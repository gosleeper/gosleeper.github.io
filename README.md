# gosleeper.github.io

My personal website and long-term publishing space.

**Live site:** [https://gosleeper.github.io](https://gosleeper.github.io)

## Purpose

This website brings together selected software projects, technical notes, project retrospectives, experiments, and a simple way to understand and contact me.

The current site is based on Jekyll and is being redesigned from an older theme into a more personal, focused experience.

## Local Preview

```bash
gem install jekyll jekyll-paginate
jekyll serve
```

Blog posts live in `_posts`. Site identity, navigation, and author information are configured in `_config.yml`.

## Roadmap

- Replace legacy theme copy and sample content
- Build a clear personal introduction and project showcase
- Improve typography, accessibility, and mobile layout
- Publish project notes and long-form writing
- Add basic SEO and privacy-conscious analytics
